# Карта Бангкока — офлайн (Bangkok Offline Map & Day Planner)

Веб-приложение (PWA) для поездки **11–15 октября**: карта Бангкока, которая
работает **без интернета**, маршруты до любой точки и алгоритм оптимальной
прогулки на весь день по вашему списку из **99 мест**.

Всё приложение — статические файлы в папке `web/`. Никакого бэкенда, никаких
онлайн-сервисов в рантайме: карта, данные и расчёты живут внутри приложения.

## Что умеет

- **Карта как у Google Maps** — плавное перемещение/зум (MapLibre GL),
  река Чао Прайя, **каналы (клонги)**, парки, **сеть именованных улиц с
  подписями** (Silom Rd, Sukhumvit Rd, Charoen Krung…), линии
  **BTS/BTS Silom/MRT** со станциями, подписи районов и все 99 мест цветными
  маркерами с названиями. Все подписи (шрифты) встроены и работают **офлайн**.
- **Работает офлайн** — service worker кэширует всё приложение; после первого
  открытия интернет не нужен. Устанавливается на телефон (PWA, «Добавить на
  экран»).
- **Умные даты 11–15 окт** — приложение знает, что закрыто в конкретный день
  (MOCA/BACC/музеи по понедельникам, TEP Bar во вторник, Чатучак и плавучие
  рынки — только в воскресенье), и что **13 окт — праздник** (храмы переполнены).
  Закрытые места помечаются и **автоматически убираются из плана**.
- **Готовые маршруты на день** (вкладка «Маршруты») — 9 тематических прогулок
  по районам. Кнопка «Построить план» превращает тему в оптимизированный
  тайминг под выбранную дату.
- **Планировщик дня** — оптимальный порядок точек (TSP), расписание с временем
  прихода/ухода, учёт часов работы, суммарное время в пути, км пешком и бюджет
  билетов в ฿.
- **Маршрут до точки** — пешком / BTS-MRT / катер по реке / такси-Grab, с
  оценкой времени и стоимости; линия рисуется на карте. Старт — от GPS или от
  любого места («Отсюда»).
- **Карточка таксисту** — название и адрес места **на тайском** (покажите
  водителю Grab/такси).
- **GPS «вы здесь»** (офлайн, через датчик телефона), **избранное**, **экспорт
  плана** (печать/PDF).

## Как открыть

Локально нужен любой статический сервер (service worker и `fetch` требуют
`http://`, с `file://` не работает):

```bash
cd web
python3 -m http.server 8099
# открыть http://localhost:8099/
```

Для использования в поездке: разместите папку `web/` на любом статическом
хостинге (GitHub Pages и т.п.), один раз откройте на телефоне при интернете,
«Добавьте на экран» — дальше работает офлайн.

## Формулы расчётов

Все формулы задокументированы в коде и настраиваются в `web/js/geo.js`
(объект `GEO.P`).

| Что | Формула | Значение по умолчанию |
|-----|---------|-----------------------|
| Расстояние | **Гаверсинус** по [lon,lat], `d = 2R·atan2(√a, √(1−a))`, `R=6371 км` | — |
| Длина пешего пути | `d_road = d · DETOUR` | `DETOUR = 1.30` |
| Скорость пешком | `v = V_база · HEAT` | `4.5 км/ч · 0.90 ≈ 4.05 км/ч` |
| Время пешком | `t = d_road / v` | — |
| Метро (BTS/MRT) | `t = walk_до_станции + ожидание + hops·τ + пересадки·θ + walk_от_станции` | `ожидание 4 мин`, `τ 2 мин/станция`, `θ 5 мин` |
| Тариф метро | `min(62, 17 + hops·3)` ฿ | — |
| Катер по реке | `t = walk + 8 мин ожидание + hops·3 мин` | тариф `20 ฿` |
| Такси/Grab | `t = d_road / 16 км/ч`; тариф `35 + max(0, км−1)·6.5` ฿ | — |
| Порядок точек за день | **TSP**: ближайший сосед + **2-opt**, внутри блоков по времени суток (утро→день→вечер) | — |

Маршрут между точками выбирает вариант с минимальным временем, но при коротком
расстоянии (< 1.2 км) предпочитает пешком. Все варианты всегда показываются —
можно выбрать вручную.

## Данные и структура

```
web/
  index.html            каркас
  styles.css            стили (светлая/тёмная тема)
  manifest.webmanifest  PWA-манифест
  sw.js                 service worker (офлайн-кэш)
  vendor/maplibre-gl.*  движок карты (офлайн, из npm)
  glyphs/               встроенные шрифты (SDF) для офлайн-подписей на карте
  data/
    places.js           99 мест: координаты, часы по дням, доступность по
                        датам 11–15, цена ฿/₽, флаги, тайские названия
    transit.js          станции BTS/MRT и пирсы на реке
    basemap.js          река, каналы, парки, дороги с названиями, районы
    themes.js           9 готовых маршрутов на день
  js/
    geo.js              геометрия и формулы времени/стоимости
    planner.js          мультимодальные маршруты + оптимизатор дня
    app.js              карта и интерфейс
scripts/
  build_data.py         генерирует data/places.js из таблицы Excel
```

### Обновить/поправить данные

Координаты меньших заведений — приближённые (по району/сои) и легко правятся:
отредактируйте таблицу `COORDS` (или другие поля) в `scripts/build_data.py`
и выполните:

```bash
pip install openpyxl
python3 scripts/build_data.py
```

## Онлайн-деплой (GitHub Pages)

В репозитории есть workflow `.github/workflows/pages.yml`, который публикует
папку `web/` на GitHub Pages при пуше. Чтобы включить:

1. GitHub → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Дождитесь, пока workflow «Deploy to GitHub Pages» отработает (вкладка Actions).
3. Откройте выданный адрес `https://<user>.github.io/localmap/` на телефоне,
   один раз при интернете, затем **«Добавить на экран»** — дальше офлайн.

Пути к ресурсам относительные, поэтому приложение работает и в подпапке
(`/localmap/`), и в корне домена.

## Точность карты и апгрейд до уличных тайлов

Карта **геопозиционно точная**: река, каналы, метро со станциями, именованная
сеть улиц центра и все места на своих координатах — с офлайн-подписями.
Дороги центра нанесены вручную по географическим данным (магистрали + ключевые
сои). Полную уличную сеть «каждого переулка» и **контуры зданий** сюда не
включали: сетевая политика окружения блокирует загрузку картографических тайлов
и данных OSM, а полный векторный слой города весит десятки–сотни МБ.

Чтобы добавить настоящие уличные тайлы и здания — один раз, при интернете,
не меняя остальную логику приложения:

1. Соберите/скачайте `bangkok.pmtiles` (например, из Protomaps) — это один файл.
2. Положите его в `web/data/` и подключите протокол PMTiles к MapLibre в
   `app.js` (`baseStyle`), добавив источник и слои улиц/зданий.
3. Впишите файл в список `ASSETS` в `sw.js`, чтобы он кэшировался офлайн.

Маркеры, маршруты, планировщик и вся остальная логика продолжат работать как есть.

## Ограничения (честно)

- Координаты популярных достопримечательностей — точные; небольших кафе/баров —
  на уровне района/переулка (правится в `build_data.py`).
- Пеший маршрут рисуется прямой линией с коэффициентом извилистости, а не по
  реальным тротуарам (полная уличная маршрутизация требует уличного графа —
  см. апгрейд выше). Оценка времени при этом реалистична.
- Часы работы и цены взяты из вашей таблицы; перед визитом их стоит перепроверять.
